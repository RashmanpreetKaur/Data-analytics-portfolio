# EV Analysis | Washington

**Tableau | Data Visualization | Data Analysis**

> **Learning Project:** This dashboard was created while following the Tableau projects and instruction from Graeme Gordon's *Data Analysis | SQL, Tableau, Power BI & Excel | Real Projects* course. It was completed as part of my hands-on learning in data analytics.

## Project Overview

This project helped me practice using Tableau to analyze electric vehicle registration data from Washington State.

The analysis explores:

* Electric vehicle type (BEV vs. PHEV)
* Vehicle manufacturers
* County-level distribution
* Model-year trends
* Interactive filtering

## What I Practiced

Through this project, I practiced:

* Importing and working with a dataset in Tableau
* Creating charts and visualizations
* Building geographic maps
* Comparing manufacturers
* Creating interactive filters
* Combining multiple visualizations into a dashboard
* Presenting data in an easy-to-understand format

## Dashboard

The dashboard includes:

* BEV vs. PHEV analysis
* Manufacturer comparison
* Top counties
* Geographic distribution across Washington
* Vehicles by model year
* Vehicle-make filtering

## Key Observations

The dashboard shows Tesla as the leading manufacturer among the manufacturers displayed and King County as the highest-count county among the counties shown.

These observations are based on the dataset and dashboard created during the learning project.
