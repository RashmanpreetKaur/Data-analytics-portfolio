# Electrical Vehicle Analysis | Washington 🚗⚡

This is my **EV Analysis | Washington** project created using **Tableau**.

The main goal of this project is to explore **Electric vehicle registration data in Washington State** and understand EV adoption patterns based on vehicle type, manufacturer, county, and model year.

## 📌 Project Overview

The dataset contains information about electric vehicles in Washington State, including:

* County
* City
* Vehicle Make
* Vehicle Model
* Model Year
* Electric Vehicle Type
* Electric Range
* Legislative District
* Electric Utility
* Location

## 📊 Dashboard Analysis

The Tableau dashboard includes:

* Total Electric Vehicles by County
* Electric Vehicle Distribution Across Washington
* Electric Vehicles by Model Year
* Comparison of EV Manufacturers
* Analysis of Electric Vehicle Types
* BEV vs PHEV Analysis
* County-level EV Mapping
* Interactive filtering by vehicle make

## 🔎 Key Insights

Some of the key observations from the dashboard include:

* **Tesla** is the leading manufacturer represented in the dataset.
* **King County** has the highest volume of electric vehicles shown in the dashboard.
* **Battery Electric Vehicles (BEVs)** represent a significant portion of the vehicles in the dataset.
* EV registrations vary across different counties and model years.
* Interactive filters allow users to explore the data by vehicle make and compare EV patterns across Washington State.
