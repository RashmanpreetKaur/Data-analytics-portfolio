# EV Analysis | Washington

## Overview

This Tableau dashboard analyzes electric vehicle data in Washington State.

## Key Analysis

* Total electric vehicles by county
* Electric vehicle distribution across Washington
* Vehicle trends by model year
* Comparison of manufacturers
* Analysis of electric vehicle types
* Interactive filtering for exploring the data

## Tools

* Tableau
* Data Visualization
* Data Analysis

## Dashboard

The dashboard provides an interactive view of electric vehicle trends and geographic distribution across Washington State.
